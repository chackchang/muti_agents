# 采集任务 API 需求说明书

## 1. 目标

一次任务分两阶段串行执行：

1. **同步采集**：循环读取机械臂坐标、电流、电压，直到 stop 或超时  
2. **点云扫描**：采集结束后扫描，写入三维点云路径与二维图像路径  

输出统一数据包 `Pack`。

---

## 2. 数据包 Pack

```json
{
  "id": "uuid",
  "data": [
    {
      "current": 0.0,
      "voltage": 0.0,
      "pose": {},
      "timestamp": "ISO8601"
    }
  ],
  "point3d_path": "string|null",
  "image2d_path": "string|null",
  "status": "collecting|scanning|completed|stopped|failed",
  "error": "string|null",
  "sample_count": 0
}
```

- `id`：创建任务时生成，与 `job_id` 相同  
- 坐标无效：跳过本周期  
- 未扫描时路径为 `null`

---

## 3. 流程

```text
function run_job(stop, skip_scan, interval_ms, max_collect_ms):
    pack = Pack(id=new_uuid(), data=[], status="collecting")

    // 阶段 A：同步采集
    while not stop and not timeout(max_collect_ms):
        pose = read_robot_pose()
        if pose is valid:
            current, voltage = read_electrical()
            pack.data.append({
                current,
                voltage,
                pose,
                timestamp: now()
            })
        sleep(interval_ms)

    pack.sample_count = len(pack.data)

    // 阶段 B：点云扫描（采集结束后才执行）
    if not skip_scan:
        pack.status = "scanning"
        point3d_path, image2d_path = point_cloud_scan()
        pack.point3d_path = point3d_path
        pack.image2d_path = image2d_path
        pack.status = "completed"
    else:
        pack.point3d_path = null
        pack.image2d_path = null
        pack.status = "stopped"

    return pack
```

约束：

- 扫描必须在采集循环结束之后开始，不得并行  
- stop 后保留已有 `data`  
- 默认 stop 后仍扫描；`skip_scan=true` 则结束为 `stopped`
